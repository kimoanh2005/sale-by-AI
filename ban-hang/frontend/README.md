# Oanh Shop frontend

Để khởi chạy ứng dụng di động Expo/React Native từ thư mục này:

```powershell
npm run start
```

Lệnh trên chuyển tiếp sang `ban-hang/mobile`. Nếu muốn chạy riêng giao diện web trong thư mục frontend, dùng:

```powershell
npm run dev
```

Các hướng dẫn chạy mobile và cấu hình backend nằm trong [`../mobile/README.md`](../mobile/README.md) và [`../backend/README.md`](../backend/README.md).
